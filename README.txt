FREE HOSTING (GitHub Pages):
1. Create/login to a free GitHub account at github.com.
2. Create a new PUBLIC repository, e.g. sea-bright-star-website.
3. Upload all files/folders from this package. Keep assets/company-logo.png inside the assets folder.
4. Open Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will give you a free address like:
   https://YOUR-USERNAME.github.io/sea-bright-star-website/

No hosting payment is required for this static website.
